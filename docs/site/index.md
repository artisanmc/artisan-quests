Artisan Quests (formerly MSQuests) gives your players quests: groups of quests that reset on a schedule
(daily, weekly), are handed out at random or in order, and pay rewards through Artisan's actions. A quest
has stages, each with objectives (break blocks, kill mobs, fish, deliver items, travel…). Quests belong to
a player, to the whole server, or to a guild with ArtisanGuildQuests.

## Requirements

| | |
|---|---|
| Server | Paper, Folia or Spigot 1.21 or newer |
| Java | 21 |
| Artisan | API 1.0.0 or newer (Artisan 1.0.0) |
| Optional | PlaceholderAPI (`%msquests_*%`), zMenu (the `MSQUESTS_QUEST_GROUP` button) |
